# BrightMart Inventory Management System
Module:Integrated Coding Project
Student: 265207

## How to run
1. Install Visual Studio with the ASP.NET and web development workload
   (this includes SQL Server LocalDB).
2. Open the .slnx file in Visual Studio.
3. Open Tools > NuGet Package Manager > Package Manager Console
   and run: Update-Database
4. Press F5 to run the application.

## Database
The application uses SQL Server LocalDB (see appsettings.json).
